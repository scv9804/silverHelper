네 PR 모두 머지하지 않고 `Claude 리뷰 대기` 라벨로 열어 두었다. 팀장은 공유 파일인 README의 로컬 데모 절차, OpenAPI의 개발 API·지역·채팅 429 계약, `ErrorCode`의 `CHAT_RATE_LIMITED`, 프론트 CI의 `npm test`를 직접 반영했다.

- **실데이터 보정:** 기존 local DB의 LIST 15,234건을 외부 재수집 없이 보정해 처음 실행에서 태그 3,193건·지역 1,277건을 수정했다. 이후 재실행은 변경 0건이었다. [행안부 통합 시도 발표](https://mois.go.kr/frt/bbs/type010/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000008&nttId=126845)에 맞춰 기존 광주광역시·전라남도 데이터 1,510건을 전남광주통합특별시로 확인했다. 원문·해시·검증 상태의 전후 체크섬은 동일했다. 빈 DB에서도 시도 16개를 반환하고 두 혜택 API의 `size=100` 허용·101 거부를 테스트했다.
- **목록·매칭 성능:** local DB의 활성 15,234건, 공개 검증 1,053건에서 각 20회 호출 중 첫 5회를 제외했다. 목록은 p50 215.9ms/p95 390.2ms, 매칭은 p50 139.7ms/p95 343.8ms였다. `EXPLAIN (ANALYZE, BUFFERS)` 실행 시간은 각각 65.4ms·16.3ms, 공유 버퍼 hit는 7,280·7,385였고 순차 스캔은 없었다. [#7 결과 댓글](https://github.com/scv9804/silverHelper/issues/7#issuecomment-6174473870)에 기록했다. 요청당 SQL 수는 `pg_stat_statements`가 비활성이라 아직 측정하지 못했다.
- **로컬 운영 호스팅:** `prod` 프로필의 백엔드·PostgreSQL·Redis·nginx를 이 PC의 `http://localhost:8088`과 LAN 주소에서 확인했다. 프론트·API 200, health `UP`, Swagger·개발 로그인 차단을 확인했다. 기존 Apache2.4와 개발 DB 15,234건은 유지했고, 운영 DB는 별도 볼륨이다. 임시 인증서로 HTTPS·HTTP 리다이렉트·ACME challenge·nginx 설정을 시험했다. 실제 도메인 발급·갱신과 휴대폰 브라우저 접속은 수행하지 않았다.
- **RAG 비용 영향:** 현재 local DB의 저장 해시와 화이트리스트 해시 불일치는 0건이다. 과거 전체 필드 해시를 가진 DB라면 목록 9,953건, AI 입력 9,956건, 검증 완료 513건이 영향을 받을 수 있다. 검증 완료 건의 추가 AI 호출 상한은 1,026회다. 실제 모델 토큰 사용량이 없어 금액은 추정하지 않았다. 호환 코드는 불필요한 재추출과 거짓 `갱신 확인 중` 표시를 막으며 [운영 기록](../../backend/src/test/java/com/silverhelper/pipeline/performance/rag-operations.md)에 이관 절차를 적었다.
- **사용량:** [`ledger.md`](../metrics/ledger.md)에 P3-0부터 작업자·수정·Codex 리뷰 19개 구간을 기록했다. 구간 합계 입력 1,718,606, 출력 230,801, 캐시 읽기 89,286,656, 총 91,236,063토큰이다. 동시 작업 구간이 있어 소요 시간을 단순 합산하지 않는다.

## 사람의 후속 작업

- doyun의 최종 Claude 리뷰 후 PR #25·#26·#27·#28의 머지 여부를 결정한다. 현재 네 PR 모두 열린 상태다.
- 같은 Wi-Fi의 실제 휴대폰에서 `http://<PC IPv4>:8088`을 확인한다. Windows 개인 네트워크 방화벽 TCP 8088 허용 여부와 Wi-Fi 클라이언트 격리를 확인한다. HTTP LAN에서는 OAuth·`Secure` 쿠키가 제한될 수 있어 로그인은 HTTPS에서 검증한다.
- AWS 계정·비용·도메인을 결정하면 [배포 절차](../deploy.md)에 따라 서버를 만들고 실제 도메인으로 Certbot 발급·`renew --dry-run --run-deploy-hooks`, OAuth 리다이렉트, DB 백업 복구를 검증한다. 실제 AWS 배포는 이번 범위가 아니다.
- [#7](https://github.com/scv9804/silverHelper/issues/7)의 요청당 SQL 수, 수동 승인 보정 대상 ID 확정, data.go.kr 트래픽 증액, 실모델 API 키를 통한 추출·비용 검증은 해당 권한과 키가 준비된 뒤 진행한다.
