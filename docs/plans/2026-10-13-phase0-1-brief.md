운영 규칙:
- worktree 경로: `D:/workspace/silverHelper-wt/<이름>`. `herdr worktree create`로 만들고, 만들어진 pane에서 `herdr agent start`.
- Codex는 `herdr agent start <이름> --kind codex --pane <id> -- --full-auto`로 실행. 처음 실행 시 폴더 신뢰 확인이 나오면 이 프로젝트 worktree이므로 승인해도 된다.
- 각 작업자에게 첫 지시로 "AGENTS.md(또는 CLAUDE.md)와 이슈 #N을 읽고 진행, 시작할 때 track start, 끝나면 PR 생성 후 track end"를 준다. track ID는 `P1-<이름>`.
- 승인 요청(blocked)이 오면: 프로젝트 안의 빌드·테스트·git·gh 명령은 승인, 프로젝트 밖 파일 삭제나 시스템 변경은 거절.
- **교차 리뷰**: Claude가 만든 PR은 Codex 리뷰어가, Codex가 만든 PR은 doyun이 리뷰. 리뷰 의견은 `gh pr review`로 PR에 남긴다(면접 자료로 남기기 위해).
- 리뷰 반영 → CI 통과 → doyun이 squash 머지 → worktree 정리. 머지 순서는 충돌이 적은 순서로 doyun이 정한다.
- 공유 파일 변경 요청이 오면 doyun이 main에서 처리한 뒤 작업자에게 rebase를 지시한다.
