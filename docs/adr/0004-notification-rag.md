# 0004. 알림과 근거 기반 챗봇

- 상태: 승인
- 날짜: 2026-10-14

## 알림

회원별 `notification_setting`은 이메일 수신 여부, 새 혜택, 마감 임박 여부와 기준 일수(기본 7일)를 저장한다. 배치는 저장된 부모님 프로필로 공개 가능한 혜택만 매칭하고 새 혜택 또는 마감 임박 조건을 만족하면 메일을 보낸다. `notification_delivery`의 `(user_id, profile_id, benefit_id, kind, event_key)` 유일 제약으로 동일 사건을 한 번만 발송한다. 전송 실패는 상태와 오류를 남기고 재시도할 수 있으며, 성공 기록을 재전송하지 않는다. Mailpit은 로컬 테스트용 SMTP다. 실제 SMTP 설정은 환경변수로 공급한다.

## 챗봇

`rag_embedding`은 혜택의 검증된 원문/요약 조각, 모델명, 원문 해시, 벡터를 저장한다. pgvector 확장을 사용한다. 공개 조건인 `benefit.status='ACTIVE' AND verified_hash IS NOT NULL`을 검색 시점에도 적용한다. `verified_hash`가 바뀌면 오래된 임베딩을 답변 근거로 사용하지 않는다. 답변은 근거의 혜택 ID, 제목, 공식 `sourceUrl`, 기준 정보와 함께 반환한다. 근거가 없거나 질문과 무관하면 답은 `모름`으로 반환한다. 프롬프트에 검색된 공개 근거 밖의 정책·자격을 만들지 말라고 명시한다.

임베딩과 답변 생성은 별도 인터페이스로 둔다. 키가 없는 로컬 환경에서는 결정적 가짜 구현을 사용하고 모든 응답에 `mock=true`를 표시한다. 가짜 응답을 실제 정책 안내로 위장하지 않는다. 키가 있을 때만 실제 모델 어댑터를 활성화한다. 사용자 질문에 개인 정보가 포함될 수 있으므로 원문 질문과 모델 응답은 기본적으로 DB에 저장하지 않는다.
